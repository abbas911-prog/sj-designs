## How the factory app works (map)
**Sign in**: name + factory password, or name + the person's own 6-digit code (21 Nov 2026). Every relay request = `{job:'fac', req, sig}` where
`sig` = HMAC-SHA256 of `req` with the phone's secret: the shared password (`FACTORY_PASSWORD` / the shop password) or the person's OWN KEY
(`FAC_PEOPLE` = {slug: {n, k, c}}; `facKeyAuth`). A phone on the shared password is handed its key in the ping answer (`facKeyGive`) and keeps it
in `sj_fac_pw`; a code-made key = sha256("sjfac|" + slug + "|" + code). **People** (op `people`, Abbas only; More → 🏭 Factory → 👥 People & phones):
list with each phone's app version / last seen / stuck messages (`FAC_PHONES`, from the ping: `v`, `dv`, `ob`, `ua`), add (code), new code, remove
(`FAC_OFF` + `FAC_KEYSONLY`: from then on the shared password works for the owner name only — `facGate` answers `needcode` / `off`, the phone signs
itself out, `authLost`). The fast lane takes keys too (`fastchk`). Requests older than 10 min are refused.
Actions carry a once-only `rid` (`FAC_ONCE`) so a retry never posts twice. Relay entry: `doPost` → `fac` → `fac0` (switch on `req.op`).

**Screens** (21 Nov 2026 look): the app always opens on **Home** (`TAB = 'home'`, `#hm`, `homeDraw` / `homeNeeds` / `homeLoad`): NEEDS YOU rows
(new messages, messages stuck on this phone, late designs, forgotten pieces, low materials, phones — owner), FACTORY NOW = 8 stage boxes, TODAY tiles
(from `workrep`, read at most every 15 min — each read costs the relay Trello calls and Google caps those per day). Bottom bar = Home · Cards · ＋ · Chats · Returns · Workers (Returns also has a row on Home, `#hret`); **More** opens from the round button top right
(`#tmore`; More = tiles `.tl`, every old button id kept). **Cards**: stage boxes on top (`GRP` = groups of `CHIPS` indexes, `groupsHtml`, `groupGo`; the
old chips `#stages` show only inside a group with more than one list), rows with pieces, who works on it (`wkOf` over the last `workrep`) and a
"Done →" button (`.rdone` → `move`, same 5-s Undo). **Card screen**: Done / Problem stay on top, under them tabs Chat · Work · Sheet · Photos
(`#ctabs`, `ctSet`; a card opens on Chat); Work tab = IN HAND NOW, DONE, then "＋ Give pieces to a worker" opening the rest (`wkArrange`, `WKGIVE`).
In the tests: `chip(page, i)`, `workTab(page, all)`, `sheetTab(page)`; `boot({ home: true })` stays on Home (default: the tests start on Cards).

**Need fabric** (21 Nov 2026, phone only — no relay / worker code): on a card in START / Cutting///START / CUTTING the chat box has **🧵 Need fabric**
(`#fabbar`, sheet `#fabs`: ONE photo, rolls 1–20, optional name) → one normal chat message with the photo. Three texts are read by another
program and must stay EXACT: `FABRIC NEEDED · <N> roll · <name>` (name optional), Abbas's `ORDERED · <vendor> · <N> roll`, and `FABRIC ARRIVED`
(button **📦 Fabric arrived**, shown while the card has an ordered fabric). `fabKind` reads a line, `fabView` gives every request its answer
(an answer belongs to the requests before it that had none; any line containing "not available" refuses the waiting ones) → chip under the
photo (`fabChip`: asked / ordered · vendor · rolls · date / not available + "Send another colour" / arrived). List mark (`fabHtml`) from `FAB`
(`sj_fac_fab` on the phone: counts per card, `fabSync` — the open chat is counted whole, background reads count on from the last line).

**Lists** (`FAC.LISTS` in relay, `CHIPS`/`NEXT`/`UR` in factory.html): SAMPLES, SAMPLE DONE, START, Cutting///START (chip "CUTTING START", 27 Oct 2026), CUTTING, IN LINE, READY FOR HAND WORK,
IN HAND WORK, CAME FROM HAND WORK, IN LINE (2), IRON/CHECKING, READY, READY 2, FINISH, FINISH SAMPLES, + RETURNS / RETURNS BACK
(made by the relay, ids in `FRET_LISTS`). Long done-lists send only their newest 60 (`FAC.LIMIT`). `op:list` = one Trello call for the
board, cached (`bigPut` in 90 KB pieces); `op:ping` (every 4 s while the phone is in use, every 30 – 60 s when nobody touches it) = "anything new?" (unread counts, Later, rooms, returns, refs, `uf` = outside calls of the last 24 h) — its Slack reads are kept `facTtl` seconds (60 with Slack's push, 30 without; `facGen` restarts them when something is written); it
also runs `facTrelloMoves` (moves made in Trello → line in the chat, every 2 min) and `facSampleNeed` (every 3 min). "Done → next" = `op:move`
(card to top of next list + Trello comment + "→ *LIST* · who" line in its chat). Also: edit, copy, add, attach (photos onto Trello),
archive (only RETURNS BACK cards). Day-count badge comes from the card id timestamp.

**Chats**: a card's chat = the replies of its Slack thread. Where it lives (`facThread`, remembered in `FTH_<cardId>`):
production cards → **#cutting**; sample cards (SAMPLES / SAMPLE DONE / FINISH SAMPLES) → **#samples-discuss**; Usman hand-work cards →
**#usmancutting** (`facUsmanOf`); new sample with USMAN tick → the #usman sample channel (`FAC_USMP`). App lines are posted as
`*Name:* text`; system lines start with `→ *` (moves, edits, photos). **Direct chat** (`dm`, `FAC_DM`) = one chosen/created channel, PRIVATE since
21 Nov 2026: Abbas + the names on `FAC_DMOK` (until Abbas chooses: names containing "ibrahim"; `facDmOk`, others get `dmno` and no row); every other
person can have his own room with Abbas (`FAC_DMP`, key `p_<slug>`, a private Slack channel `direct-<slug>` made by the bot, `facPRoom`) — a room like
#cash (`facXRoomsFor`: Abbas sees all, a person only his own). Not closed: the worker's `dm` op reads any channel id a signed-in phone asks for.
Unread / Catch up = `facUnread` vs per-person `FSEEN_<NAME>`; 📌 Later = `FLATER_<NAME>`. Files go to Slack in original quality
straight from the phone (`upurl` → upload → `up`). Outbox on the phone (IndexedDB) keeps sending until Slack has it.

**Fast lane** (`fast-worker.js`): phone → Cloudflare → Slack/Trello in ~0.2 s for reading chats (`thread`, `dm`), text `post`, files
(`/f`, streamed originals), and Trello `tlist`/`tatts`/`timg`/`tmove`. Phone key = sha256("sjfast|"+password), checked once with the relay
(`job:'fastchk'`). Worker link set in the app (status line → Fast lane → `op:fastset`, stored `FAC_FAST`). Worker secrets:

**Doorbell** (live): private ntfy.sh topic (`facLive` → `FAC_LIVE`); the app listens via EventSource. Rings: `c=<cardId>` (chat changed),
`c=list:<id>` (list changed → reload), `c=ret:<n>`, `s:<channel>:<thread>` (from Slack Event Subscriptions → worker `/slack`; app maps it
to the card with `refs`). No message text ever goes on the doorbell. Polling stays as the safety net. Phone notifications: 🔔 → ntfy app,

**Work per worker** (21 Oct 2026): the machine workers = the "W - Name" people of the AL MUTAGADED GARMENTS Google Sheet (NOT the Trello
